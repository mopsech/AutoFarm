## 📖 About

**AutoFarm** is an open-source script for Roblox designed to automate repetitive tasks in games. The project is built with a focus on **security**, **transparency**, and **ease of use**.

## 📥 Installation

### Method 1: Via Developer Console

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ваш-репозиторий/AutoFarm/main/main.lua"))()
```

### Method 2: Via Executor

1. Copy the contents of `main.lua`
2. Paste it into your Roblox Executor
3. Run the script
